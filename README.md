# SenPlay

An independent, from-scratch player for iOS and Android, built from the *observable
behaviour contract* of the analysed reference app — **no original code, no original assets**.

What it reproduces:

| Area | Contract source |
|---|---|
| `senplay://` / `senplayer://` deep links (`x-callback-url/play`, `download`, `importserver`, `importicon`) | `URLSchemes.md` shipped with the reference build |
| Media servers: WebDAV, Emby / Jellyfin / 飞牛 | server browse + direct-play endpoints |
| Playback: local files, network URLs, external subtitles, speed, resume position | UI behaviour |
| Library: URL list, play history, per-item progress | UI behaviour |

Reverse-engineering evidence for the reference build lives in
`docs/EVIDENCE.md` (produced with a hand-written Mach-O parser, because REA's
macOS-only tooling is unavailable on Windows).

## Layout

- `android/` — Kotlin + Jetpack Compose + Media3/ExoPlayer (minSdk 24, targetSdk 35)
- `ios/` — SwiftUI + AVPlayer, project generated by XcodeGen
- `.github/workflows/android.yml` — signed release APK
- `.github/workflows/ios.yml` — unsigned IPA

## Build

Both platforms are built on GitHub Actions; no local SDK is required.

```bash
gh workflow run android.yml --repo <owner>/senplay -f create_release=true
gh workflow run ios.yml --repo <owner>/senplay
```

Android release signing reads `APP_KEYSTORE`, `APP_KEYSTORE_PASSWORD`,
`APP_KEY_ALIAS`, `APP_KEY_PASSWORD` from the environment (CI secrets) and
falls back to an unsigned build when they are absent.
